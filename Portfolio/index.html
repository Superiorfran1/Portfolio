Proyectos

Lo que he construido

Un proyecto full stack completo, pensado como una plataforma real de compra-venta de segunda mano.

FernanPop

Aplicación web de compra-venta de artículos de segunda mano, con gestión completa del ciclo de una venta: desde la publicación del producto hasta la valoración tras la compra.

Java MySQL HTML CSS JavaScript

Funcionalidades principales

  • Registro e inicio de sesión de usuarios
  • Publicación de productos a la venta
  • Solicitud de compra: un comprador muestra interés y el vendedor la acepta
  • Valoraciones de productos tras la compra
  • Listado y consulta de todos los productos disponibles
  • Avisos automáticos por Telegram al administrador ante cambios en productos y usuarios
  • Notificaciones por correo electrónico a los usuarios implicados en cada operación
