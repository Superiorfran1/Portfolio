# Portfolio — Francisco Cantero Maestro
 
Portfolio personal y currículum web de **Francisco Cantero Maestro**, desarrollador Full Stack apasionado por el frontend y con el objetivo de enfocar su carrera hacia el desarrollo de videojuegos.
 
🔗 **Demo:** _añade aquí el enlace una vez publicada (GitHub Pages, Vercel, Netlify, etc.)_
 
## ✨ Características
 
- Diseño responsive (móvil, tablet y escritorio)
- Modo claro / oscuro (respeta la preferencia del sistema y permite cambiarlo manualmente)
- Navegación entre secciones sin recarga de página (Inicio, Proyectos, Sobre mí, Contacto)
- Sección de proyectos con ficha detallada, capturas y enlaces a repositorios
- Descarga del CV en PDF directamente desde la web
- Copia rápida del email de contacto al portapapeles
- Sin dependencias externas de frameworks: HTML, CSS y JavaScript puro
## 🛠️ Tecnologías utilizadas
 
- HTML5
- CSS3 (variables CSS, Flexbox, Grid)
- JavaScript (Vanilla)
- Google Fonts (Fraunces + Inter)
## 📁 Estructura del proyecto
 
```
├── index.html      # Estructura y contenido de la web
├── styles.css      # Estilos y temas (claro/oscuro)
├── script.js       # Lógica: navegación, tema, copiar email, descarga de CV
└── README.md
```
 
## 🚀 Cómo verlo en local
 
No necesita instalación ni dependencias. Basta con clonar el repositorio y abrir `index.html` en el navegador:
 
```bash
git clone https://github.com/Superiorfran1/<nombre-del-repositorio>.git
cd <nombre-del-repositorio>
```
 
Después, abre `index.html` con doble clic o usando una extensión tipo *Live Server*.
