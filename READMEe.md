# Portfolio — Francisco Cantero Maestro
 
Personal portfolio and online resume of **Francisco Cantero Maestro**, a Full Stack developer passionate about frontend development, aiming to move his career towards video game development.
 
🔗 **Demo:** _add the link here once it's live (GitHub Pages, Vercel, Netlify, etc.)_
 
## ✨ Features
 
- Responsive design (mobile, tablet and desktop)
- Light / dark mode (respects system preference and can be toggled manually)
- Navigation between sections without page reloads (Home, Projects, About, Contact)
- Detailed project section with screenshots and repository links
- CV download in PDF directly from the site
- Quick copy-to-clipboard for the contact email
- No external framework dependencies: plain HTML, CSS and JavaScript
## 🛠️ Technologies used
 
- HTML5
- CSS3 (CSS variables, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Fraunces + Inter)
## 📁 Project structure
 
```
├── index.html      # Structure and content of the site
├── styles.css      # Styling and themes (light/dark)
├── script.js       # Logic: navigation, theme, copy email, CV download
└── README.md
```
 
## 🚀 Running it locally
 
No installation or dependencies required. Just clone the repository and open `index.html` in your browser:
 
```bash
git clone https://github.com/Superiorfran1/<repository-name>.git
cd <repository-name>
```
 
Then open `index.html` by double-clicking it, or serve it with something like the *Live Server* extension.
